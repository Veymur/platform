# Hardware fixtures

No hardware fixture is verified yet. Galaxy A23 / Android 14 + Polar Verity Sense collection remains D8 and the open hardware checks in the main plan. Do not label emulator SDK injection as hardware.

Keep original personal ZIPs outside this catalogue (for example in the already ignored `diagnostic-exports/`). Run the D5 validator and D6 converter with explicit `--kind hardware` into a private output path, then review the pseudonymized data, limitations and source-reproduction check. Only deliberately selected, small, reviewed derivatives belong here; each needs independent `*.expected.json` assertions and an explanation of their basis. The converter never adds/stages a file in Git.

Origin is operator-declared; passing a schema/transform check does not prove use of a real sensor or hardware background reliability. Original IDs/maps/dates are not needed in a public expectation file. See the [catalogue workflow and limits](../README.md).
